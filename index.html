// 项目介绍

关于本项目

这是一个计算机安全方向的本科生科研课题，聚焦脑机接口（BCI）与AI安全的交叉领域。项目已完成英文论文初稿，计划投稿CCF推荐期刊/会议。我们提出了一种硬件安全架构，从根源上切断BCI系统中反馈通道的神经注入攻击面。

// 招募岗位

招募岗位

🔧

嵌入式系统 / 硬件实现

基于ESP32和光耦隔离模块搭建可穿戴原型，完成延迟、功耗等性能测试。要求熟悉单片机开发（Arduino/ESP32均可），有电路搭建和调试经验。加分项：用过光耦、了解SPI/I2C通信协议。

💻

信号处理 / 算法仿真

用Python/MATLAB处理脑电信号数据集，完成攻击注入仿真和统计分析。要求熟练使用Python或MATLAB，修过信号处理或机器学习相关课程。加分项：接触过EEG/脑电数据，用过scikit-learn等机器学习库。
